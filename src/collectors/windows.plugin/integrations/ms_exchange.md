# MS Exchange


<img src="https://netdata.cloud/img/exchange.svg" width="150" alt="MS Exchange"/>


Plugin: windows.plugin
Module: PerflibExchange

<img src="https://img.shields.io/badge/maintained%20by-Netdata-%2300ab44" alt="Maintained by Netdata" />

## Overview

Monitor Exchange transport queues, Active Directory access, client activity, HTTP proxy traffic, and background workloads.


The collector reads registered Microsoft Exchange performance counters through Windows Perflib.


This collector is only supported on the following platforms:

- windows

This collector only supports collecting metrics from a single instance of this integration.


### Default Behavior

#### Auto-Detection

The collector is enabled by default. Charts appear when Exchange registers the corresponding performance objects and counters.



#### Performance Impact

The default configuration for this integration is not expected to impose a significant performance impact on the system.

The configuration file name for this integration is `netdata.conf`.

The file format is a modified INI syntax. The general structure is:

```ini
[section1]
    option1 = some value
    option2 = some other value

[section2]
    option3 = some third value
```
You can edit the configuration file using the [`edit-config`](https://github.com/netdata/netdata/blob/master/docs/netdata-agent/configuration/README.md#edit-configuration-files) script from the

