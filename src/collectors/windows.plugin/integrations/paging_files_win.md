# Paging Files (Win)


<img src="https://netdata.cloud/img/windows.svg" width="150" alt="Paging Files (Win)"/>


Plugin: windows.plugin
Module: PerflibPagingFile

<img src="https://img.shields.io/badge/maintained%20by-Netdata-%2300ab44" alt="Maintained by Netdata" />

## Overview

This collector monitors the size and usage of each paging file (`pagefile.sys`) on Windows systems.

Use it to see which paging file is filling up and how a system-managed file grows. The host-wide `mem.swap`
and `mem.committed` charts are different: they report system commit charge against the commit limit, which
counts physical memory plus all paging files.


It reads the `Paging File` object from Perflib once per collection. For each file, `% Usage` gives the pages
in use and the file size in pages; both are converted to bytes with the system page size.


This collector is only supported on the following platforms:

- windows

This collector only supports collecting metrics from a single instance of this integration.


### Default Behavior

#### Auto-Detection

Every paging file the system reports is charted automatically. Charts for a removed paging file become
obsolete; a file added later appears without restarting Netdata.



#### Performance Impact

One Perflib query per collection of a small kernel object with one instance per paging file.

#### via File

The configuration file name for this integration is `netdata.conf`.
Configuration for this specific integration is located in the `[plugin:windows:PerflibPagingFile]` section within that file.

The file format is a modified INI syntax. The general structure is:

```ini
[section1]
    option1 = some value
    option2 = some other value

[section2]
    option3 = some third value
```
You can edit the configuration file using the [`edit-config`](https://github.com/netdata/netdata/blob/master/docs/netdata-agent/configuration/README.md#edit-configuration-files) script from the
Netdata [config directory](https://github.com/netdata/netdata/blob/master/docs/netdata-agent/configuration/README.md#locate-your-config-directory).

```bash
cd /etc/netdata 2>/dev/null || cd /opt/netdata/etc/netdata
sudo ./edit-config netdata.conf
```

## Metrics

Metrics grouped by *scope*.

### Per paging file

These metrics refer to a single paging file.
