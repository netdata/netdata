## Overview

Read how much anonymous memory the kernel has reserved for running processes. This is the amount of swap that would be needed to back all allocated anonymous memory, the same accounting Linux reports as Committed_AS.

The plugin reads the `vm.swap_reserved` sysctl. The kernel tracks it whatever the `vm.overcommit` setting is.

This collector is supported on all platforms.

This collector only supports collecting metrics from a single instance of this integration.
