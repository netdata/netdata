# hw.acpi.battery


<img src="https://netdata.cloud/img/freebsd.svg" width="150" alt="hw.acpi.battery"/>

<img src="https://img.shields.io/badge/maintained%20by-Netdata-%2300ab44" alt="Maintained by Netdata" />

## Overview

Read the remaining battery capacity that the ACPI battery driver reports for all batteries combined.

The plugin reads the `hw.acpi.battery.units` and `hw.acpi.battery.life` sysctls. When the host has several batteries, the kernel combines them into one capacity percentage.

This collector is supported on all platforms.

This collector only supports collecting metrics from a single instance of this integration.


### Default Behavior

#### Auto-Detection

The module stops on hosts without the ACPI battery driver, where the `hw.acpi.battery` sysctls do not exist. When the driver reports no batteries, the chart is removed; when it cannot read a valid capacity, the chart shows a gap.


#### Performance Impact

The default configuration for this integration is not expected to impose a significant performance impact on the system.
