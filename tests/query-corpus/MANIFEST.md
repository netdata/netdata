# Query Corpus Manifest

Human mirror of `manifest.json`. Every case records what it proves and, once a
fix has landed, which PR delivered it.

Nothing here records an expected outcome. A contract either holds or it does
not, and only running it can answer that — so a broken contract FAILS, on
master and on every branch, whether or not it is already known. Run the suite
to see which ones the query engine does not hold today; it prints the whole
set at the end.
